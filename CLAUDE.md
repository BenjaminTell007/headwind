# Headway

If you're working on the frontend (`web/`, `design/`), read `web/CLAUDE.md` first and run `web/tools/team.sh` to see the other frontend Claude's notes before you edit anything.

For everyone:
- Work on your own branch (`<name>'s-branch`), then merge to `frontend`, then `main`. Pushing to `main` redeploys Railway.
- Pull before you edit, commit and push small pieces often, never force-push.
- Never commit `PRIVATE.md` or any key.
